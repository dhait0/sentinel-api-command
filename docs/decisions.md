# Decisions

## Use Next.js route handlers

Next.js route handlers keep this demo lightweight while still showing REST API structure and typed responses.

## Keep persistence mocked

Persistence is intentionally mocked in this repository. A later project can introduce NestJS, Prisma, PostgreSQL, Docker Compose, and migrations.

## Bilingual but concise

English and Spanish labels are paired directly in the UI so clients can understand the project quickly without switching locales.

## Distinct visual direction

This repo uses a technical command-console style with dark shell background, light API panels, monospaced endpoint text, and state codes.
