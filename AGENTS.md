# Mission

Build a bilingual REST API command demo that looks like an enterprise integration operations product.

## Product rules

- Keep this repo visually distinct from prior portfolio demos.
- Focus on API contracts, endpoint health, mock incidents, and integration ownership.
- Use concise English and Spanish copy throughout the UI and documentation.
- Use only mock endpoints, fake incidents, fake systems, and synthetic payloads.
- Do not expose real credentials, internal schemas, private URLs, or business logic.
- Avoid generic dashboard composition; this product should feel like an API operations console.

## Repository standards

- Include `README.md`, `docs/`, `LICENSE`, `.env.example`, `.gitignore`, and screenshots.
- Keep code production-ready with TypeScript strict mode.
- Document architecture, implementation, decisions, and future improvements.
